# Saalaram Website Assets & Resources

This directory contains static assets served directly by Vite.

## Folder Structure

- `public/assets/logos/` — Store brand logos, favicon, and emblem files (SVG, PNG)
- `public/assets/images/` — Store high-resolution photos, banners, project showcase images
- `public/assets/icons/` — Store custom vector icons and graphics

## Usage in Code

In HTML:
```html
<img src="/assets/logos/logo.png" alt="Saalaram Logo" />
```

In JSX:
```jsx
<img src="/assets/images/hero-bg.jpg" alt="Hero Background" />
```
